# Prompt de Auditoria

Audite a resposta jurídica contida em:

`evidencias/resposta_inicial.md`

Utilize exclusivamente:

* `apoio/caso_sanitizado.md`
* `apoio/fonte_1.md`
* `apoio/fonte_2.md`

Para cada afirmação relevante, verifique:

1. se ela está apoiada por uma das fontes;
2. se a fonte realmente sustenta a afirmação;
3. se houve criação de fatos não presentes no caso;
4. se houve utilização de informação jurídica não autorizada;
5. se existe exagero ou conclusão mais ampla do que aquilo que a fonte permite afirmar.

Classifique cada achado como:

* manter;
* corrigir;
* excluir.

Para cada achado, indique o motivo da classificação e a fonte correspondente.

Não acrescente novas informações jurídicas durante a auditoria.

A auditoria deve se limitar a verificar a resposta produzida anteriormente.
