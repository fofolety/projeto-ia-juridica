# Limites e Sigilo

## Natureza do projeto

Este repositório foi desenvolvido exclusivamente para fins acadêmicos e utiliza um caso jurídico inteiramente fictício.

Nenhuma informação utilizada no projeto corresponde a cliente real, processo judicial real, documento real ou informação protegida por sigilo.

Os nomes utilizados no relato foram criados exclusivamente para a elaboração deste exercício.

## Limites de utilização

As informações contidas neste repositório não devem ser utilizadas como orientação jurídica para casos reais sem análise profissional e verificação das fontes jurídicas aplicáveis.

A IA utilizada no fluxo não deve receber dados pessoais desnecessários, informações protegidas por sigilo profissional ou documentos de clientes.

## Regra de sanitização

Antes da utilização do relato por ferramenta de inteligência artificial, informações que possam identificar pessoas, empresas, processos ou documentos reais devem ser removidas ou substituídas por informações fictícias.

Neste projeto, o relato bruto foi transformado em uma versão sanitizada antes de sua utilização na etapa de consulta baseada em fontes.

## Finalidade

O objetivo do repositório é demonstrar um fluxo de análise jurídica com uso controlado de fontes, verificação das respostas, auditoria e revisão humana.
